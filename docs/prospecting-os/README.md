# Compatibility documentation path

This directory is retained temporarily because existing release-candidate scripts and historical references use the `prospecting-os` path.

The canonical repository product is **Codistan Sales Automation**, and the production application is **Prospect Desk**. Documents in this directory must be normalized to that identity before the release candidate merges. Prospecting OS may remain only as a compatibility or internal release vocabulary where migration risk requires it.
